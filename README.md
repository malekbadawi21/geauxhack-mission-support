# geauxhack-mission-support

## AI-assisted code

Files written or edited with Claude Code (Claude Opus 5.5):

- `src/lib/schema.ts` — zod schemas + TypeScript types for Extraction, Reading, and Event.
- `src/lib/extract.ts` — `extractReport()`: calls Gemini with a JSON response schema and validates the reply with zod.
- `src/lib/verify.ts` — `verifyQuotes()`: marks each reading/event verified if its `source_quote` is a verbatim substring of the report.
- `scripts/extract.ts` — CLI that runs extract + verify on a report, prints tables, and saves JSON to `data/extractions/`.
- `.env.example` — empty template for `GEMINI_API_KEY` and `GEMINI_MODEL`.
- `.npmrc` — `legacy-peer-deps=true` to work around an npm 10 install crash.
- `package.json` — added the `extract` script and project name (rest generated by `create-vite`).
- `tsconfig.app.json`, `tsconfig.node.json` — enabled `strict`; moved Node-only files (`scripts/`, `src/lib/extract.ts`) to the Node config.
- `.gitignore` — appended Node/Vite entries (`node_modules`, `dist`, etc.).

Generated by the `create-vite` react-ts template (not AI): `index.html`, `vite.config.ts`, `tsconfig.json`,
`.oxlintrc.json`, `public/`, `src/main.tsx`, `src/App.tsx`, `src/App.css`, `src/index.css`, `src/assets/`.
