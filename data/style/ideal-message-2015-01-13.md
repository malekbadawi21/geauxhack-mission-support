# Message-to-Earth style guide

This is a style guide, not content. Write the message only from facts in the tool results.

## Why it's written this way
Earth is 20+ minutes away each way. A question and its answer take 40+ minutes, so every message
must be complete enough that Mission Control can act without asking anything back.

## Structure (in this order, 80–120 words total)
1. STATUS: one sentence. Overall state and the single biggest issue.
2. WHAT HAPPENED: one or two sentences. The key event, when it happened, and the key number with its unit.
3. WHAT THE CREW IS DOING: one sentence. Actions already taken.
4. OTHER SYSTEMS: one sentence. Other issues briefly; say "nominal" for systems that are fine.
5. REQUEST: one sentence. The decision needed from Earth, and by when.
6. NEXT UPDATE: one short sentence. When the crew will report again.

## Tone
- Calm, factual, specific. Plain words, no drama, no filler, no exclamation marks.
- Bottom line first.
- Every number has a unit. Approximate values are marked as approximate ("about 360 L", "~360 L").
- One clear request rather than several vague ones.
